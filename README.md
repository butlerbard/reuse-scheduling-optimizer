# 預算科目流用最佳解工具

把預算變更表（Excel 或 CSV）放在工具資料夾、雙擊一個檔案，就會自動算出「哪個科目要流用多少錢到哪個科目」，並盡量讓轉移筆數最少。結果是一份 Excel 檔：第 1 頁是原始資料、第 2 頁是所有轉移的總覽，第 3 頁起每個流用組別各自一頁。

## 下載與啟動

1. 在本頁上方按綠色的「Code」→「Download ZIP」，下載後解壓縮到桌面或任何資料夾。
2. 雙擊資料夾裡的 **`啟動流用計算.bat`**。
   - 第一次執行會自動準備執行環境（需要網路，約 1～3 分鐘）；電腦沒有 Python 時，會詢問是否自動安裝。
   - 之後每次執行約 2 秒就會開始計算。

詳細步驟、畫面說明與常見問題，請在解壓縮後用瀏覽器開啟 **`使用說明.html`**。

## 每次使用

1. 把 `.xlsx`、`.xls` 或 `.csv` 預算表放在工具資料夾裡（和 `啟動流用計算.bat` 同一層），一次可以放好幾個。
2. 雙擊 `啟動流用計算.bat`。算完後會自動用 Excel 打開結果 `原檔名_流用結果_日期時間.xlsx`（存在工具資料夾）。

- 計算成功的原檔會移到**資源回收筒**（需要時可以還原）；有錯誤的原檔留在原處，依視窗訊息修正後再雙擊一次。
- 結果檔看完請移到其他資料夾。留在工具資料夾的話，下次啟動時會詢問是否移到資源回收筒（按 `Y` 移走、按 `N` 保留，保留的會被當成新檔案再算一次）。

## 輸入表格式

可以直接使用 `範本` 資料夾裡的 `流用預算表_範本.xlsx`（差異欄已放好公式）或 `流用預算表_範本.csv`；`.xls` 檔也可以讀取。

第一列為欄位名稱：`預算編號`、`預算名稱`、`原預算金額`、`流入後金額`、`差異`（順序不拘，可以有其他欄位）。Excel 只讀第一個工作表。

- 差異 ＝ 流入後金額 − 原預算金額；負數是流出，正數是流入。
- 預算編號格式為「單位-年度預算來源編碼-科目編號」，例如 `AZ0-115F001-008`。
- 去掉最後一段科目編號後相同者（例如 `AZ0-115F001`）屬於同一個流用組別，只有同組才能互相流用；每組差異合計必須為 0。

## 先試用看看

`測試資料` 資料夾有四份假資料。把它們**複製**（不是移動）到工具資料夾後執行，就能看到各種結果：

| 檔案 | 會看到的結果 |
| --- | --- |
| `1_正常資料_單一組別.csv` | 成功，結果 Excel 有 3 頁：原始資料、排列後總覽、1 個組別 |
| `2_正常資料_多組別分頁.csv` | 成功，結果 Excel 有 5 頁：原始資料、排列後總覽、3 個組別各一頁 |
| `3_錯誤資料_欄位內容.csv` | 失敗，視窗一次列出所有錯誤與列號 |
| `4_錯誤資料_組別合計不為0.csv` | 失敗，視窗指出哪一組的差異合計不為 0 |

## 計算方式

每個流用組別各自計算：先讓轉移筆數最少，筆數相同時再讓「拆成多筆的科目」最少。每組最多計算約 30 秒；兩項都確定是最少時，視窗標示「最佳解」，否則標示「可行方案」並說明原因。不論哪一種，結果都已核對每個科目的金額正確、沒有跨組流用。
